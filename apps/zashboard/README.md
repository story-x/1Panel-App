## 📖 项目简介

**Zashboard** 是一个专为 Clash / Mihomo 设计的现代化 Web 仪表盘控制面板，通过 Clash RESTful API 与内核通信，提供极具美感且响应迅速的图形化交互界面。

### ✨ 核心特性

- 🎯 **现代优雅的 UI 设计**: 支持自适应深色/浅色模式，多种精美字体与主题。
- ⚡ **实时状态监控**: 实时展示上传/下载速率、内存占用、连接数统计与流量图表。
- 🔄 **节点与策略组管理**: 智能排序、快速节点测速、切换代理策略组。
- 📜 **规则管理与追踪**: 清晰直观查看分流规则，快速定位请求匹配路径。
- 🌐 **活跃连接监控**: 查看当前所有活动的 TCP/UDP 连接详情，支持一键断开连接。
- ⚙️ **配置快速调整**: 轻松修改运行模式（Rule / Global / Direct）、TUN 设置、日志级别等。
- 📱 **多端自适应**: 完美适配桌面端、平板以及移动端浏览器。
- 🚀 **极度轻量**: 纯前端静态架构，依托 Caddy 容器服务，内存占用低至数兆。

## 🚀 1Panel 部署说明

### 1. 安装配置

在 1Panel 应用商店安装 Zashboard 时，只需设置：
- **端口 (`PANEL_APP_PORT_HTTP`)**: 宿主机访问 Zashboard Web 界面的端口（默认为 `7899`，可按需修改）。
- **时区 (`TZ`)**: 默认为 `Asia/Shanghai`。

### 2. 访问与连接配置

安装完成后，在浏览器中打开 `http://<你的服务器IP>:7899`。

初次打开面板时，输入您的 Clash / Mihomo 内核后端信息：
1. **API 地址 (Host / IP)**: 运行 Clash / Mihomo 的服务器 IP 或域名（若同机部署可填 `127.0.0.1` 或服务器内网 IP）。
2. **API 端口 (Port)**: 内核配置文件中 `external-controller` 对应的端口（默认通常为 `9090`）。
3. **密钥 (Secret)**: 内核配置文件中 `secret` 对应的认证密钥（若未设置可留空）。

> 💡 **提示**: 建议在内核配置中启用并允许跨域访问，以便浏览器顺利发起 RESTful 请求。

## ❓ 常见问题

### 1. 无法连接到 Clash / Mihomo 核心？
- 检查后端核心的 `external-controller` 是否监听在 `0.0.0.0:9090` 而非仅 `127.0.0.1:9090`（若从其他设备浏览器访问）。
- 检查服务器防火墙与安全组是否放行了控制器端口（如 9090）。
- 检查密钥（Secret）是否输入正确。
- 若通过 HTTPS 访问 Zashboard 面板，浏览器可能会阻止对 HTTP API 发起混合内容请求（Mixed Content），建议统一使用 HTTP 或为核心配置 SSL 证书。

### 2. 如何切换语言或字体？
- 点击右上角或设置面板，可自由选择多国语言（简体中文/繁体中文/English等）以及界面字体与主题偏好。
